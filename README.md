# Photo Manipulation

An early (2017) C# Windows Forms project — a small "Image Manipulator" desktop app built while learning .NET.

> **Status:** archived learning project. Kept for history; not maintained.

## What's in it

| Window | Purpose | State |
|---|---|---|
| **Watermarker** (main) | Pick input/output folders for batch watermarking | UI only — processing never implemented |
| **Image Scraper** | Search Google Images and download the results to a folder | Worked at the time; Google's page format has since changed |
| **Meme Generator** | Caption images | Empty form stub |
| **About** | Author / version info | — |

## Stack

- C# / Windows Forms
- .NET Framework 4.5.2
- Visual Studio solution: `PhotoManipulation.sln`

## Building

Open `PhotoManipulation.sln` in Visual Studio on Windows (with the .NET Framework 4.5.2 targeting pack) and build.
